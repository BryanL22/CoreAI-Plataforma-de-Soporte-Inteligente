# CoreAI-Plataforma-de-Soporte-Inteligente
CoreAI es una solución integral diseñada para automatizar la gestión de tickets de soporte técnico. El sistema permite a los usuarios crear tickets y chatear con un asistente virtual, mientras que el equipo de soporte gestiona y clasifica las solicitudes en tiempo real gracias a una orquestación inteligente con IA.
